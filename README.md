# StellarPixels
High-Resolution TIFF Image Viewer

A Python-based desktop application developed with PyQt5 for viewing and navigating high-resolution TIFF images. The application provides a graphical interface designed to handle large scientific and astronomical images efficiently, allowing users to inspect detailed image data through an intuitive visualization environment.

The viewer supports high-resolution TIFF files and provides tools for image navigation, zooming, and detailed inspection. PyQt5 is used to build the graphical user interface, while Python handles the image processing and application logic.

The project is designed as a lightweight and accessible solution for working with high-resolution imagery, particularly useful for scientific, astronomical, and technical visualization.
